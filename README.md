# Domin Software – Mateusz Domin

![Domin Software](logo.webp)

I develop and maintain PHP and Laravel applications, integrate business systems through APIs, and build multilingual websites and admin panels. At [Domin Software](https://dominsoftware.it/), I work directly with companies across Poland from defining the scope through deployment and further development.

## DominPress

[DominPress](https://dominsoftware.it/dominpress) is my Laravel platform for multilingual websites and applications with custom business logic. Its open-source components cover content management, media and theme integration.

## Open-source packages

| Project | What it does |
| --- | --- |
| [Laravel CMS](https://github.com/dominservice/laravel-cms) | Manages multilingual pages, content blocks and categories in a configurable admin panel. |
| [Laravel Media Kit](https://github.com/dominservice/laravel-media-kit) | Reuses image and video assets across content and delivers responsive image variants. |
| [Laravel Theme Helper](https://github.com/dominservice/laravel-theme-helper) | Manages Laravel themes, metadata, hreflang, structured data and sitemaps. |

| [Data Locale Parser](https://github.com/dominservice/data_locale_parser) | Provides localized country, currency, language and address data. |
